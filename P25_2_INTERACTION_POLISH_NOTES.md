# P25.2 Interaction polish

- Desktop app sidebar now auto-collapses when the user clicks anywhere in the main page after expanding/using navigation.
- PlanoraHub Mail now has a dedicated collapsible mail rail. Its state is remembered locally; collapsed mode keeps compact icons for Compose, All mail, Inbox/replies, My mail, Shared with me, Drafts, and Templates. Mobile retains the readable horizontal folder experience.
- Shared Files Manage Access no longer includes a redundant “All” tab. It opens on Staff and exposes only Staff, Departments, Teams, and Roles as direct access categories.
- No database migration is required for this patch.
