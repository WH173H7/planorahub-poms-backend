# PlanoraHub P30.2 — Staff UI Polish

Frontend-only patch for the Staff work console.

## Changed
- `components/delivery/staff-home-view.tsx`
- `components/leads/my-work.tsx`
- `components/leads/staff-lead-workspace.tsx`
- `components/staff/staff-polish.module.css` (new)

## Scope
- My Day: clearer KPI hierarchy, overdue emphasis, focus banner, task/lead queues and follow-up presentation.
- My Work: denser lead table, next-action/deadline visibility, pursuit progress, better mobile lead cards.
- Assigned Lead: stronger lead header, current-stage emphasis, sticky workspace tabs, cleaner overview/tasks, contacts and activity timeline.
- No backend/API/SQL/auth/workflow logic changes.
- No manual Change Stage capability added.

## Apply
From the PlanoraHub project root:

```bash
rsync -av /path/to/planorahub-p30-2/components/ planorafrontend/components/
```

Then validate from `planorafrontend`:

```bash
pnpm typecheck
pnpm lint
pnpm build
```

Do not commit/push until all three pass.
